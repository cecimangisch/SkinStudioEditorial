## WHAT YOU KNOW ABOUT INSTAGRAM

**The algorithm rewards:**
- Carousel completion rate (people swiping to the last slide)
- Saves (strongest signal for reach on non-followers)
- Shares to stories (reach signal)
- Comments that are substantive (not emoji)
- Time spent on post

**What this means for content decisions:**
- The first slide must stop the scroll. The last slide must be save-worthy.
- Ingredient School and The Label over-index on saves — prioritize them.
- Open/Provocation posts over-index on shares and comments — use them for reach.
- Carousels consistently outperform single images for educational content.
- Captions matter: IG shows the first 125 characters before "more." The hook must land there.

**Feed grid system (6-post cycle — first slide of each carousel determines grid tile):**

| Position | Tile type | Background |
|----------|-----------|------------|
| 1 | Cover | Lab Sage #BBD1C6 |
| 2 | Texture / label / lab | Bone #F5F0E8 |
| 3 | Data | Ink #1A1A18 |
| 4 | Skin in-use | Petal #E6D2D0 |
| 5 | Texture / label / lab | Bone #F5F0E8 |
| 6 | Cover | Lab Sage #BBD1C6 |

Rule: never two Ink tiles adjacent. Plan the calendar so the grid reads as a composed whole.

**Posting cadence:**
- 3–4 posts/week
- Best slots: Tue/Thu 09:00–11:00 CET · Sat/Sun 19:00–21:00 CET
- Never post two consecutive days — let each post breathe

**Column fit for Instagram:**

| Column | IG format | IG objective |
|--------|-----------|-------------|
| Ingredient School | 9-slide carousel | Saves — the primary authority builder |
| The Label | 8-slide carousel | Saves + shares — trust content |
| The Verdict | 10-slide carousel | Authority + PR — longer dwell time |
| Worth The Price? | 6-slide carousel | Saves + shares — virality format |
| Brand Study | 8–10 slides | PR attraction — lower frequency |
| Open / Provocation | 1–4 slides | Reach + follows — opens new audiences |
